# 百事AA导入核对体验完善

目标：保留现有格式、显式确认和一对一去重保护，提高重叠时间段导入的核对效率。

## 实施顺序

1. 核对服务：候选搜索与分页；全文件收支及新增、跳过、未决的笔数与金额摘要；仅待确认筛选。所有金额使用Decimal，筛选不改变确认门禁。
2. 批次历史：复用AuditLog，在账单提交的同一事务保存成功报告；按本人及当前账本权限过滤、分页读取。保留文件SHA256，不保存文件名或原文件，不做撤销。旧批次缺少汇总时明确提示。
3. Web：候选分页搜索、明确关联按钮、新旧差异标记、待确认筛选与下一未决、对账摘要和历史入口；三语言同步。
4. 格式引导：明确支持五种单币种普通收支以及如何处理不支持格式。混币、退款、转账、复杂AA需要独立语义设计与合成/实际样本，不猜测金额。
5. 验证：后端候选第20条之外的选择、搜索/分页/筛选、全文件门禁、精确金额与历史权限/回滚；前端测试与构建；备份后部署测试实例、真实API与浏览器验收。

## 边界

生产实例及移动端不变，公开推送和生产部署另行授权。临时预览环境保留；不清空永久测试数据。历史只记录成功批次，失败由当前执行错误提示呈现，不能伪造成功报告。上传预览仍为30分钟内存令牌，不增加持久草稿。

## 状态

开发、回归、自查和测试实例部署已完成，等待用户验收。四项核对体验功能及格式指引已实现；混币、退款、转账、复杂AA仍需补充样本和语义方案，不在当前支持范围。生产发布及远端推送尚未执行。
