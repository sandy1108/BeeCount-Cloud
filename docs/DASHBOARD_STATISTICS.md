# 首页统计视角与分类构成

## 个人全局偏好

在Web右上角用户菜单进入“个人资料”，选择“首页统计视角”：

| 项目 | 结余视角（默认） | 支出视角 |
| --- | --- | --- |
| 首页主金额 | 当前周期结余 | 当前周期总支出 |
| 主累计曲线 | 累计收入减累计支出 | 累计支出，不抵扣收入 |
| 收入、支出卡片 | 保留 | 保留 |
| 收支走势图及收入/支出排行 | 保留 | 保留 |
| 储蓄率 | 保留 | 隐藏，剩余卡片补满布局 |

两种视角使用完全相同的交易数据和统计接口。收入始终记录并参与原有收支计算。切回结余视角恢复原有首页主指标与储蓄率。

配置按登录用户保存，应用于其查看的所有账本，其他用户不受影响。没有账本级覆盖或本机localStorage优先级。它与账本`statistics_mode`独立：后者控制普通/雪季周期，两种视角均能搭配任意周期模式。

## API与升级

- `GET /profile/me`返回`statistics_focus: balance | expense`；`PATCH /profile/me`可只更新这个字段。
- 非法非空值返回422；省略或null表示保持原值。新用户或无Profile记录时默认balance。
- 迁移`0023_profile_statistics_focus`仅给`user_profiles`新增非空默认balance列，不改任何交易或账本周期。
- 修改沿用`profile_change`通知和Profile重读，其他Web会话可刷新服务端偏好。旧客户端发送外观JSON整体替换时也不会清掉独立的统计视角。
- 本轮仅后端和Web实现；Flutter Android/iOS与鸿蒙端的设置与首页适配待开发，不能将字段兼容等同于移动端支持。
- 切回旧代码时，旧迁移器可能不认识0023。发布前须演练保留新列的代码回退；不自动降级删列或用旧备份覆盖已同步数据。

## 饼图中的“其他”

按金额排序展示前5个正金额分类，其余合并为一个灰色分块。这是固定数量规则，不是小于某个占比阈值，因此合并后的“其他”可能很大。

“其他（N个分类）”旁的展开区域列出其全部构成：分类名称、金额、笔数及占全部支出的比例。中心显示真实正金额分类数，不再用最多6个图形分块替代实际数量。真实账本中名为“其他”的分类与图表合并分块通过独立标记区分，不因同名混用配色。

展开只解释本图当前周期的构成，不修改分类，也不改变现有分类详情的日期范围。未分类的支出沿用现有未分类显示规则。

## Web布局与桌面安装

首页资产构成与收支走势采用等宽两列，与支出分类等卡片对齐，窄屏堆叠显示。

应用不再自动弹出桌面安装提示。手动入口在“个人资料→添加到桌面”：浏览器提供安装能力时按钮可用；否则显示浏览器菜单及Safari主屏幕添加说明。已在独立应用运行或本次完成安装时显示已添加。普通浏览器标签页无法可靠识别是否已在其他窗口安装。应用版本更新提示不受此调整影响。
